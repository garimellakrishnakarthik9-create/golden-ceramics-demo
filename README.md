# Golden Ceramics – Inventory Management Demo

A simple inventory management prototype for Golden Ceramics.

## Features
- Inventory dashboard
- Product management
- Stock receiving
- Damaged stock reporting
- Staff stock requests
- Admin approval and rejection
- Inventory movement history

## Technology
- HTML
- CSS
- JavaScript

## Project Status
Prototype for client demonstration. Uses sample data and is not intended for live business transactions.
